文件批量重命名

如何使用脚本

  1. 在本页选择或拖拽需要重命名的文件（文件名仅在你的浏览器本地读取，绝不会上传到任何服务器）。
  2. 在上方设定重命名规则（查找替换、前缀、后缀、编号、大小写、去空格等），下方实时预览确认新文件名无误、无重复。
  3. 点击「下载 Windows 脚本 (.bat)」或「下载 Mac/Linux 脚本 (.sh)」，把下载的脚本文件放进待重命名文件所在的同一个文件夹。
  4. 进入该文件夹运行脚本：Windows 直接双击 .bat 文件；Mac / Linux 打开终端，执行 bash rename_files.sh。
  5. 文件即按预览结果批量改名。建议先复制少量文件到单独的测试文件夹试运行一次，确认无误后再处理全部文件。
